Konfigurasi IP Address Debian 12

1. Pengertian

IP Address adalah alamat identitas perangkat yang digunakan untuk berkomunikasi dalam jaringan komputer.

2. Tujuan

* Mengatur alamat IP server.
* Menghubungkan server ke jaringan.
* Memahami konfigurasi jaringan Linux.

3. Melihat IP Address

Gunakan perintah:

ip address

Perintah tersebut digunakan untuk melihat alamat IP dan interface jaringan.

4. Melihat Gateway

Gunakan perintah:

ip route

5. Melihat DNS

Gunakan perintah:

cat /etc/resolv.conf

6. Pengujian Koneksi

Gunakan perintah:

ping -c 4 8.8.8.8

7. Hasil

Tambahkan screenshot hasil pemeriksaan IP Address dan koneksi jaringan.

8. Kesimpulan

Konfigurasi IP Address merupakan bagian penting dalam administrasi jaringan agar server dapat berkomunikasi dengan perangkat lain.
