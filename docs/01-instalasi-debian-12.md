Instalasi Debian 12

1. Pengenalan

Debian 12 (Bookworm) merupakan sistem operasi Linux yang bersifat open-source dan dapat digunakan sebagai sistem operasi server.

2. Persiapan

Perangkat dan kebutuhan:

* Komputer atau laptop
* File ISO Debian 12
* VirtualBox (opsional)
* RAM minimal 2 GB untuk praktik dasar
* Ruang penyimpanan yang cukup

3. Tahapan Instalasi

1. Download ISO Debian 12 dari situs resmi.
2. Siapkan VirtualBox atau media instalasi.
3. Boot menggunakan ISO Debian 12.
4. Pilih menu Graphical Install.
5. Atur bahasa dan lokasi.
6. Konfigurasi jaringan.
7. Atur hostname dan akun pengguna.
8. Atur partisi penyimpanan.
9. Selesaikan proses instalasi.
10. Restart sistem.

4. Kesimpulan

Instalasi Debian 12 merupakan langkah awal untuk mempelajari administrasi sistem Linux dan konfigurasi server.
